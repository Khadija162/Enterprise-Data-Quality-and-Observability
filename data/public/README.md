# Open dataset source

Iris is a historic open research dataset hosted by the UCI Machine Learning Repository (https://archive.ics.uci.edu/dataset/53/iris, DOI https://doi.org/10.24432/C56C76), CC BY 4.0. The included CSV is based on the public scikit-learn Iris mirror (https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/datasets/data/iris.csv); the first metadata line was removed and numeric target codes were mapped to species names. Attribution: R. A. Fisher, *The use of multiple measurements in taxonomic problems* (1936). No sensitive data.
